# ブルアカ戦術対抗戦リザルト OCR

ブルーアーカイブの**戦術対抗戦リザルト**スクリーンショットから、編成キャラクター名を一括で読み取り、CSV ファイルに出力するツールです。

Google スプレッドシートへのインポートを想定した UTF-8（BOM 付き）形式で出力します。

## 機能

- 戦闘履歴画面の左右 6 人分（計 12 人）のキャラ名を OCR で読み取り
- 2 行表示の名前（例: `シロコ＊テ` / `ラー`）に対応
- キャラ名辞書による OCR 結果の補正
- 配置制約（Striker / Special）を考慮した辞書マッチング
- 辞書にない名前の検出と警告ログ出力
- NVIDIA GPU 利用時は自動で GPU 加速（未対応環境は CPU にフォールバック）

## 動作環境

| 項目 | 要件 |
|------|------|
| OS | Windows 10 / 11 |
| Python | 3.12 推奨 |
| スクリーンショット解像度 | **3840×2160 固定**（PC版でスクショした際の解像度） |
| 画面 | 戦闘履歴ポップアップ（ウィンドウ位置・サイズが一定） |
| GPU（任意） | NVIDIA GPU + CUDA 対応 PyTorch |

> **注意:** 解像度や UI 配置が異なる場合は、座標の再キャリブレーションが必要です。

## ファイル構成

```
ba-screenshot-ocr/
├── setup.bat              … 初回セットアップ
├── calibrate.bat          … 座標キャリブレーション（初回またはずれた場合）
├── extract.bat            … 名前抽出（メイン）
├── config.json            … 名前行の切り出し座標
├── characters.txt         … キャラ名辞書
├── name_dictionary.py     … 辞書マッチング・別名定義
├── extract_names.py       … 抽出処理本体
├── calibrate.py           … 座標調整 GUI
├── generate_characters.py … Wiki から辞書を更新
├── requirements.txt       … Python 依存パッケージ
└── setup.ps1              … セットアップスクリプト（内部用）
```

## 導入手順

### 1. Python をインストール

[Python 公式サイト](https://www.python.org/downloads/) から **Python 3.12** をインストールしてください。

インストール時に **「Add python.exe to PATH」** にチェックを入れてください。

### 2. セットアップを実行

`setup.bat` をダブルクリックします。

初回は以下が自動で行われます。

- 依存パッケージのインストール（EasyOCR, OpenCV など）
- CUDA 対応 PyTorch のインストール（GPU 利用時の加速用）
- EasyOCR 日本語モデルのダウンロード（初回 OCR 実行時）

> **GPU について**
>
> - NVIDIA GPU がある場合、処理が高速化されます
> - RTX 50 系（Blackwell）では CUDA 13.0 版 PyTorch（cu130）を使用します
> - GPU が使えない環境では CPU で動作します（時間はかかりますが問題なく処理できます）

### 3. 座標を調整（初回のみ）

`calibrate.bat` をダブルクリックし、3840×2160 の戦闘履歴スクショを 1 枚選択します。

1. **左チーム行** を選択し、左側 6 人分の名前が収まる矩形をドラッグ
2. **右チーム行** を選択し、右側 6 人分の名前が収まる矩形をドラッグ
3. **保存** をクリック

設定は `config.json` に保存されます。同じ解像度・UI 配置であれば、再調整は通常不要です。

> 同梱の `config.json` が環境と合っていれば、この手順はスキップできます。数枚試してから判断してください。

### 4. 名前を抽出

`extract.bat` をダブルクリックし、スクリーンショットが入ったフォルダを選択します。

処理が完了すると、選択したフォルダに CSV が出力されます。

## 出力ファイル

| ファイル | 内容 |
|----------|------|
| `character_names.csv` | 読み取り結果（メイン出力） |
| `character_names_unknown.txt` | 辞書に未登録の名前一覧（該当時のみ） |
| `character_names_warnings.txt` | 未登録名の詳細ログ（ファイル名・列・名前） |

### CSV の形式

```csv
filename,left_1,left_2,left_3,left_4,left_5,left_6,right_1,right_2,right_3,right_4,right_5,right_6
screenshot_001.png,シロコ＊テラー,ネル（バニーガール）,...
```

- `left_1`〜`left_6` … 左チーム（Win 側）1 列目〜6 列目
- `right_1`〜`right_6` … 右チーム（Lose 側）1 列目〜6 列目
- 3840×2160 以外の画像はスキップされます

## コマンドラインでの実行

フォルダを GUI で選ばずに指定する場合:

```bat
python extract_names.py "C:\path\to\screenshots"
```

## カスタマイズ

### キャラ名辞書（`characters.txt`）

1 行 1 キャラ名で記述します。行末に配置制約を付けることができます。

```
# 末尾に st（1-4列）または sp（5-6列）を付けて配置制約を指定（省略時は両方）
シロコ＊テラー    st
ミチル（ドレス）    sp
ユウカ
```

| 記号 | 意味 | 対応列 |
|------|------|--------|
| `st` | Striker（1〜4 列目想定） | left/right_1 〜 _4 |
| `sp` | Special（5〜6 列目想定） | left/right_5 〜 _6 |
| 省略 | 制約なし | 全列 |

新キャラが追加された場合は、このファイルに 1 行追加するか、下記スクリプトで Wiki から再生成してください。

### Wiki から辞書を更新

```bat
python generate_characters.py
```

[ブルアカ Wiki キャラクター一覧](https://bluearchive.wikiru.jp/?%E3%82%AD%E3%83%A3%E3%83%A9%E3%82%AF%E3%82%BF%E3%83%BC%E4%B8%80%E8%A6%A7) から最新のキャラ名を取得します。

既存の `characters.txt` にある **st / sp 指定は引き継がれます**。

### OCR 別名（`name_dictionary.py`）

OCR が特定の文字列を誤認識しやすい場合、`ALIASES` に別名を追加できます。

```python
ALIASES = {
    "シロコ*テラー": "シロコ＊テラー",
    "三ネ": "ミネ",
    ...
}
```

### 座標（`config.json`）

`calibrate.bat` で調整するか、直接編集します。

```json
{
  "resolution": [3840, 2160],
  "left_row":  { "x": 263, "y": 1736, "width": 1355, "height": 121 },
  "right_row": { "x": 2200, "y": 1739, "width": 1333, "height": 110 },
  "columns": 6
}
```

## 処理時間の目安

| 環境 | 700 枚程度 |
|------|-----------|
| NVIDIA RTX 5060Ti | 約 3〜7 分 |
| RYZEN 9 9950X | 約 10〜15 分 |

初回実行時は OCR モデルの読み込みで追加で 10〜30 秒ほどかかります。

## トラブルシューティング

### 名前がずれている・空欄が多い

- `calibrate.bat` で座標を再調整してください
- 名前行の矩形が、6 人分の名前（2 行表示を含む）をすべて覆っているか確認してください

### 特定の名前だけ誤認識される

1. `character_names_unknown.txt` で未登録名を確認
2. `characters.txt` に正しい名前を追加
3. それでも OCR 結果が固定で間違う場合は `name_dictionary.py` の `ALIASES` に追加

### GPU が使われない

コンソールに `GPU が使えないため CPU で実行します` と表示される場合:

- NVIDIA ドライバが最新か確認
- `setup.bat` を再実行して CUDA 版 PyTorch を入れ直す
- RTX 50 系以外の GPU では cu126 版が必要な場合があります（`setup.ps1` の PyTorch インストール行を変更）

### 解像度違いの画像がスキップされる

本ツールは **3840×2160** 専用です。別解像度のスクショは `[スキップ]` として処理されません。
